# Kickr

## KICKR Click (Android app)

Two modes, switched on the screen:

- **ERG**: the KICKR holds a power. The Zwift Click's **+** raises it; **B** or the left pod's **−** lowers it.
- **Free ride**: ERG off. The KICKR rides a flat road and the same buttons change virtual gears (24, like Zwift's).

Outside Zwift the left Click pod stops after about a minute, so the app restarts it every 50 seconds (a few seconds' gap each time).

Download: https://github.com/mnali43/Kickr/releases/download/app/KickrClick.apk

The app's source is in `android/`. GitHub builds it automatically on every change.
